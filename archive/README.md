# Archived v5 source

The original public v5 source and regression suite are preserved in this ZIP and in commit `7fec9a9`. Extract it into a separate directory to use the frozen v5 protocol. Its historical validation does not validate the modified v6 implementation. Do not run its old fingerprint assertions against v6 or merge v5 scores with v6.

SHA256: `269cf5c7091cba1593f8bb6069e1a6fa49a712729d9169228829ae10e16ee863`. The archive excludes credentials, gated raw tasks and private browser captures.
